# Renvill Game Assets & CDN Storage

Repositori penyimpanan aset resmi untuk **Renvill Game** ([renvillgame.vercel.app](https://renvillgame.vercel.app)).

Disediakan secara global melalui jaringan multi-CDN cepat **jsDelivr**:
`https://cdn.jsdelivr.net/gh/daryfajar/renvill-assets@main/`

### Struktur Direktori:
- `games/[game-slug]/cover.jpg` : Cover gambar game resolusi tinggi.
- `torrents/` : File `.torrent` game dan installer digital.
- `tools/` : Software pembantu, emulator, patch game, dan utility installer (.rar / .zip).
